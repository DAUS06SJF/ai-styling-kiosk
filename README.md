# ASK(AI-STYLING-KIOSK)

매장을 방문한 고객이 옷걸이에서 옷을 선택하면, 행거 위 스크린/키오스크에서 AI가 고객 취향에 맞는 코디를 실시간으로 제안하는 서비스입니다.
온라인의 편리함과 오프라인의 감각적 경험을 연결해 매장 내 고객 경험을 혁신하는 것이 목표입니다.
